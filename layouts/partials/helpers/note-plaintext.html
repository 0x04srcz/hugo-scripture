{{- /* Returns a page's rendered content as plain text, shaped to read the way the page reads. Used for note share text and for the syndication manifest, so what gets posted by hand and what gets posted by a script are identical. Structure has to be captured *before* plainify, because plainify drops the tags that carry it and leaves only the source's own whitespace -- so two paragraphs would come out separated by a single newline, indistinguishable from a soft wrap. Sentinels survive plainify, and get turned into real breaks afterwards:
-> one newline (an explicit line break: verse, address) start of a code line -> one newline (Chroma wraps each line in a span whose trailing newline plainify would swallow, which turns a multi-line shell snippet into one unrunnable line) end of a block -> blank line (paragraph, list item, heading, quote) htmlUnescape last, so entities (’, &) become the characters a reader actually sees rather than being pasted literally into a toot. Usage: {{ $text := partial "helpers/note-plaintext.html" . }} */ -}} {{- $body := .Content -}} {{- $body = $body | replaceRE `(?i)` "@@SZLF@@" -}} {{- /* Chroma line wrappers, both flavours: class-based (noClasses = false) and inline-styled (noClasses = true). */ -}} {{- $body = $body | replaceRE `(?i)` "@@SZLF@@" -}} {{- $body = $body | replaceRE `(?i)` "@@SZLF@@" -}} {{- $body = $body | replaceRE `(?i)` "@@SZPARA@@" -}} {{- $body = $body | plainify | htmlUnescape -}} {{- $body = $body | replaceRE `[ \t]*@@SZLF@@[ \t]*` "\n" -}} {{- $body = $body | replaceRE `\s*@@SZPARA@@\s*` "\n\n" -}} {{- $body = $body | replaceRE `[ \t]+` " " -}} {{- $body = $body | replaceRE `[ \t]+\n` "\n" -}} {{- $body = $body | replaceRE `\n{3,}` "\n\n" -}} {{- $body = trim $body "\n \t" -}} {{- return $body -}}
